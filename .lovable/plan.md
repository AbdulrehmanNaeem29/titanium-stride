# Titanium Equestrian website

## Visual direction

- **Palette:** Titanium teal `#238F93`, deep navy `#071E2B`, ink `#102C38`, clean white `#FFFFFF`, warm-grey `#F3F5F4`, muted steel `#9AACB1`, and a restrained performance accent `#66C7C2`.
- **Typography:** Cormorant Garamond for confident editorial headings and Manrope for crisp athletic body copy, labels, and controls.
- **Composition:** cinematic equestrian action photography, assertive editorial scale, clipped/diagonal image treatments, fine teal rules, circular brand motifs, and restrained motion. The design will avoid rustic styling, generic business cards, oversized rounded shapes, and template-like sections.
- **Homepage order:** action-led hero → Antarès sponsorship and credibility strip → Partnership / Progress / Performance method → training program preview → trainer introduction → results/testimonials → audience pathways → closing booking band.

## Build

- Create a shared sticky header, mobile slide-in navigation, sponsor-aware footer, and reusable closing enquiry band across all pages.
- Build `/` as the complete homepage with generated equestrian action photography, clear lesson/program pathways, testimonials, and booking calls to action.
- Build `/training-programs` as the primary conversion page with five detailed programs, fit guidance, inclusions, eventing methodology, pricing language, enquiry actions, training-video preview, and practical FAQs.
- Build `/about` with a trainer biography framework, philosophy, sponsorship context, action imagery, and clearly marked placeholders for credentials the owner must verify.
- Build `/testimonials` with sample success stories and progress/result formats clearly presented as placeholder content, not fabricated claims.
- Build `/contact` with an accessible enquiry form, program and experience selectors, phone/service-area details, scheduling expectations, and social links. Submission will provide a polished confirmation state without pretending a booking backend exists.
- Add page-specific search/social metadata, semantic headings, descriptive image alternatives, keyboard navigation, reduced-motion support, lazy loading, and touch-friendly mobile behavior.

## Content and assets

- Generate a cohesive set of Pacific Northwest eventing photographs for the hero and key page moments; optimize and import them locally.
- Use a refined text-and-symbol Titanium Equestrian lockup until the official logo file is supplied, without inventing a replacement brand identity.
- Keep unknown facts explicit: trainer name, certifications, years/levels, exact facility, prices, Facebook URL, and Instagram handle will remain clearly replaceable placeholders rather than invented claims.

## Validation

- Verify navigation, mobile menu, testimonial controls, FAQs, and enquiry form behavior.
- Check desktop and mobile layouts for overflow, readable contrast, image framing, and stable interactive states.
- Confirm the final build is clean and every page has unique metadata.
